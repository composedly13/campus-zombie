# Campus Zombie Survival 🧟

좀비 바이러스가 퍼진 대학 캠퍼스에서 살아남아 **도서관 옥상**까지 탈출하는 텍스트 기반 서바이벌 게임의 기획 저장소입니다.

> 오픈소스SW 개론(SH207) 중간 과제 「Git Quest」 실습용 저장소입니다.
> 실행되는 게임 코드는 없고, 기획 문서(Markdown)만 Git으로 관리합니다.

## 게임 개요
- **배경**: 좀비 바이러스가 확산된 대학 캠퍼스
- **목표**: 좀비를 피해 도서관 옥상까지 탈출
- **주요 시스템**: 플레이어 체력, 랜덤 이벤트, 멀티 엔딩

## 파일 구성
| 파일 | 내용 |
|---|---|
| `game/rules.md` | 게임 기본 규칙 (체력, 진행 방식) |
| `game/events.md` | 랜덤 이벤트 목록 |

## 개발 현황
- v1.0: 기본 규칙과 랜덤 이벤트 기획 완료
- v1.1: 밸런스 조정, 멀티 엔딩 추가 예정

## 게임 플레이 팁
- 체력이 50 아래로 떨어지면 매점 쪽 경로로 돌아가 구급상자를 노려 보세요.
- 정전 이벤트가 나오면 다음 구역에서 좀비를 만날 확률이 높으니, 체력을 미리 채워 두세요.
- 생존자 동아리원의 보호 효과는 도서관 직전 구역까지 아껴 두는 것이 좋습니다.
